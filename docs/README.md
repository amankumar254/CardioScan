# CardioScan Documentation

This directory is reserved for the project report, presentation, and pipeline documentation.

The source repository intentionally excludes large generated training artifacts and the MIT-BIH dataset. The dataset can be downloaded through the preprocessing script.

The current repository snapshot contains the source code, setup files, evaluation artifacts, and documentation metadata. Binary project documents from the working package were reviewed locally but could not be transferred through the current GitHub connector's text-only file upload interface.
